A brief that survives forwarding

What can a single HTML brief do without JavaScript?

Recommendation

Keep the finding and its sources in the page. Use native links, a disclosure for optional explanation, and print styles for sharing.

An editorial recommendation based on the documented facts below.

Link to the evidence

An anchor with an href can link to another page or a location within this document. [1]

Let readers open detail

details provides a disclosure; its summary labels the content readers can expand or collapse. [2]

Give print its own layout

A CSS @media print rule can change styles when printing to paper or PDF. [3]

Try the optional explanation

This disclosure works without a script. The finding and all references remain outside it, so collapsing this detail does not hide the evidence.

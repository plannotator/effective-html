What must be true at launch

The release is ready when the highest-risk user journeys are verified on real devices, support has a clear escalation path, and owners can explain every remaining exception.

Decision rule
Unknown behavior blocks the release. A known limitation may ship only with an owner, user-facing language, and a dated follow-up.

Decisions already made

  • Keep the rollout staged at 10%, 35%, then 100%.
  • Use the existing account recovery path; defer the redesigned flow.
  • Publish the migration guide before the production promotion.

Open question

Can the Android keyboard regression be contained to the new compose surface, or does it affect the existing editor as well?

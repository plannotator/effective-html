---
title: Effective HTML guide
description: A short guide to wireframes, mockups, prototypes, diagrams, decks, and other HTML artifacts made with agents.
---

Agents can build wireframes, mockups, prototypes, diagrams, decks, and small
interfaces. These can be easier to understand than a long prompt or Markdown
file.

This is a short guide to those uses. You do not need to install a skill or
follow a fixed process. Use the examples as references and ask your agent for
the artifact you need.
